# emart-app -- is used to learn how we can write the vagrantfile for making the VM and using them to deploy the application.

Create a VM and install docker, docker compose on it using Vagrantfile.
Take a clone using git clone
Go inside the emartfolder 
Read Docker compose.yml file 
Run the docker compose using, "docker compose up" command and hence we have deployed an microservices applcation on containers using Vagrantfile.
